# archive/registers/ — verbatim register snapshots (the archive of `_REGISTER.md`)

One file per outgoing register version, `archive/registers/{YYYY}/REGISTER_v{N}_{YYYY-MM-DD}.md` (year folder = year of the outgoing `register_date`), written unchanged in the same commit that supersedes it (MODEL §7.4a session end step 4, §7.5). From MODEL v4.5.0 each snapshot has a twin, `REGISTER_v{N}_{YYYY-MM-DD}.csv`: the outgoing `register.csv`, byte for byte, same N and date. The first lean version (the v4.5.0 rebuild) has no outgoing `.csv`, so its predecessor has only the `.md`. Append-only. Git history of `_REGISTER.md` is the secondary net; these files exist so that any session — including API-only or mobile ones — can retrieve a past state without git.
