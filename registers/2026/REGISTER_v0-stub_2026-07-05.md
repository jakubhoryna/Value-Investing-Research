# GSC Register — Master Watchlist

Source of truth for every name analysed in this project. One row per company, latest memo version only — replace the row after each REVIEW. Maintained manually: copy the register row printed at the end of each analysis into this table, then re-upload this file to project knowledge.

**Legend.** Verdict: BUY / WATCH / AVOID / DNAF · Past & Future: STRONG / ADEQUATE / WEAK · SF: PASS / FAIL · Trigger band: approximate price below which cheapness flips to CHEAP (binding metric in brackets) · Next review: date, event, or price condition that should prompt a REVIEW chat.

**Sweep protocol.** In a downturn, open a chat and ask for a sweep: WATCH rows are price-checked against trigger bands and ranked IN RANGE / NEAR / FAR. IN RANGE names get a full REVIEW before any decision — trigger bands age as fundamentals move.
