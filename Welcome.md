# GSC Vault — Welcome

Good Stocks Cheap research vault. Start here:

- [[_REGISTER]] — master watchlist + portfolio layer (source of truth; version, date, and counts in its front matter)
- [[MODEL]] — live operative framework (`instructions/MODEL.md`, fetched at every Claude session start)
- [[BOOTSTRAP]] — token-redacted mirror of the project instructions
- `memos/` — one memo per company-version, never overwritten
- `registers/archive/` — verbatim snapshots of superseded register versions

Sessions run through the Claude project; the bootstrap in project settings governs session
start, mode detection (ANALYSE / REVIEW / SWEEP / MODEL / RECONCILE), and commit gates.

*Framework output, not investment advice.*
